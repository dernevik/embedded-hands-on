| Lab | Tema | Praktiskt moment | Lärandemål |
|---|---|---|---|
| **9** | Dual-core boot | Starta Cortex-M7 och Cortex-M4, låt båda annonsera `BOOTING → READY` via shared memory | Du ska kunna förklara hur en multicore-startup kräver synkronisering mellan separata execution contexts, och kunna observera båda kärnornas state i debuggern. |
| **10** | Inter-core communication utan OS/RTE | Implementera enkel mailbox i shared RAM, först med polling och sedan notification/hardware semaphore | Du ska förstå varför shared memory i sig inte är ett kommunikationsprotokoll och kunna resonera om ownership, synchronization, atomicity, timeouts och stale data. |
| **11** | Startup/shutdown coordination | Bygg startup- och shutdown-state machines där en kärna behöver tjänster från den andra före OS/RTE-start respektive efter deras stopp | Du ska kunna förklara varför startup och shutdown kräver explicita protokoll och kunna hantera readiness, acknowledgements, timeout och komponenter som stängs ned i olika ordning. |
| **12** | Memory protection och partitioner | Skapa separata MPU-regioner för två simulerade partitioner samt ett explicit shared-memory-område; framkalla otillåten access | Du ska kunna förklara hur memory protection isolerar mjukvara, demonstrera en protection fault och analysera vilken access och vilket minnesområde som orsakade felet. |
| **13** | Fault isolation mellan cores | Introducera hang, illegal memory access eller annan fault på ena kärnan och låt den andra upptäcka felet via heartbeat/timeout | Du ska kunna skilja mellan fault detection och fault containment samt resonera om hur resten av systemet kan upptäcka och reagera när en kärna eller tjänst slutar fungera. |
| **14** | Integrerad mini-ECU | Kombinera dual-core startup, IPC, tjänsteägarskap, memory protection, runtime-kommunikation, shutdown och fault handling i ett litet ECU-liknande system | Du ska kunna följa systemet genom `RESET → INIT → RUN → SHUTDOWN`, förstå vilka kommunikationsmekanismer som finns tillgängliga i respektive fas och felsöka problem som korsar core-, partition- och lifecycle-gränser. |
